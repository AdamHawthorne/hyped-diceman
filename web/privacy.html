ROLLF

Privacy Policy

Last updated: September 4, 2026

1. Overview

RollF is a Discord bot that provides daily number rolls, statistics and leaderboards. This Privacy Policy explains what information RollF stores and how it is used.

2. Information We Store

To provide its functionality, RollF may store:

  • Discord user ID
  • Discord username
  • Roll results and related statistics
  • Date and time associated with rolls
  • Discord server (guild) ID
  • Discord channel ID used for automatic daily rolls
  • Top.gg vote status and an associated cosmetic color index

3. How We Use Information

Stored information is used to operate and maintain RollF's features, including daily rolls, statistics, leaderboards, server configuration and Top.gg voting rewards.

4. Information We Do Not Intentionally Collect

RollF does not intentionally collect passwords, payment information, private Discord messages, or precise location information.

5. IP Addresses and Logs

When application event logging is enabled, an IP address may be recorded in an application log in connection with invalid or expired Top.gg webhook requests. IP addresses are not used as part of RollF's normal user profiles or statistics.

6. Third Parties

RollF uses Discord to provide its service and may interact with Top.gg for vote-related functionality and webhook events. RollF does not sell user information.

7. Data Retention

Roll and statistical data may be retained as necessary to provide historical statistics and leaderboard functionality. Server configuration data may be removed when it is no longer associated with a server. Operational logs are subject to the bot's configured log retention.

8. Your Choices

For questions about information associated with your Discord account, or to request applicable data removal, contact rollf-bot@tuta.io.

9. Changes to This Policy

This Privacy Policy may be updated when RollF's functionality or data handling changes. The date above indicates the latest revision.
